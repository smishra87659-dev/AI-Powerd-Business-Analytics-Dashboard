# 📊 AI-Powered Business Analytics Dashboard

An advanced, end-to-end data analytics platform designed to clean raw business data, track critical KPIs, and generate automated Profit & Loss (P&L) visualizations. It features integrated **AI Chat and Voice Query** capabilities, allowing stakeholders to interact directly with their data using natural language.

## 🎯 Project Objective
The primary objective of this project is to empower business managers and non-technical stakeholders to extract immediate strategic insights without requiring knowledge of complex SQL queries or programming. It eliminates manual reporting overhead through automated data preprocessing and predictive modeling.

---

## 🚀 Key Features
- **Automated Data Cleaning:** Automatically handles missing values, removes duplicates, and treats outliers upon data ingestion.
- **KPI Tracking & P&L Analysis:** Real-time interactive charts tracking net revenue, gross profit margins, and operational costs.
- **AI-Powered Insights:** Users can query data using natural text or voice commands (e.g., *"What was the top-selling product category last month?"*).
- **Predictive Analytics:** Implements built-in forecasting models to predict future sales trends and revenue pipelines.

---

## 🛠️ Tech Stack & Tools
- **Language:** Python 🐍
- **Libraries:** Pandas, NumPy (Data Manipulation), Scikit-learn (Predictive Modeling)
- **Web App Framework:** Streamlit (For Interactive UI)
- **Visualization:** Plotly / Matplotlib / Seaborn
- **AI Integrations:** LLM API (For Text & Voice Query Processing)

## ⚙️ How to Run the Project

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   cd AI-Powerd-Business-Analytics-Dashboard
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Note: If you haven't created a requirements file yet, run: `pip install streamlit pandas scikit-learn plotly`)*

3. **Launch the Application:**
   ```bash
   streamlit run app.py
   ```
